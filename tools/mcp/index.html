Koskari Corpus MCP

A Model Context Protocol server for the Koskari language: documentation, a reference for special forms, macros, layouts and reader behavior, and a corpus of verified example programs with expected results at the read, expand, compile and eval phases. The dataset is baked into the image, so every query is answered from memory with no outbound request.

Two kinds of path, and they are not interchangeable. Feature paths -- special/compile/cond, layout/try -- are what list_features returns, and search_examples is the only tool that takes them, as feature_path. Reference paths -- reference/specials/compile-cond.md, agents/index.md, anything under examples/ -- are what get_reference takes. Handing a feature path to get_reference finds nothing.

What bridges them is the references field on every record: list_features to choose a feature, search_examples feature_path=<it> for the examples, then get_reference on a path from their references for the documentation behind them.

A feature filter is an exact match unless it ends in a slash, which makes it a prefix: special/compile/ matches the whole family, while special/compile matches nothing.
