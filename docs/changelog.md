# Changelog

This changelog is for user-visible changes: language behavior, command-line
usage, documentation, and public tooling.

---

## 0.1.0

Initial documented development release.

Highlights:

- Lisp-style forms with parenthesized calls.
- Indentation-based layout for friendly blocks such as functions, conditionals,
  loops, classes, imports, and exception handling.
- Compile-time special forms, macros, and macro expansion helpers.
- Python interoperability through imports, objects, calls, context managers, and
  exceptions.
- A custom evaluator and bytecode reference for advanced users.
- Beginner, from-Python, guide, reference, pattern, corpus, and API
  documentation sections.
