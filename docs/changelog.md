# Changelog

This page is reserved for user-visible release notes.

## Current documentation snapshot

The documentation now includes beginner-friendly tutorial material, a shared
guide path, reference pages for language forms, API pages, and project notes.
Until formal release entries are published, use the package version and project
release process as the source of truth for installable artifacts.

## What belongs here

Future entries should focus on changes users need to know about:

- new language forms or syntax,
- changed behavior,
- deprecations and migration notes,
- CLI or packaging changes,
- documentation additions that help readers find a new feature.

Internal refactors should appear only when they affect users directly.
