`examples/` when one exists.

## Using these recipes

1. Complete [Install and run](../start/install-run.md).
2. Follow the [From Python track](../start/from-python/index.md) for narrative
   context.
3. Open the linked `.ki` file, run it with `koskari`, then adapt the pattern in
   your own module.
