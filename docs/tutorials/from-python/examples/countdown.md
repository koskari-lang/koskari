# Countdown

A `while` loop with `decr!` and an `else:` peer that runs when the counter
reaches zero -- used in the from-python [Data and control](../data-and-control.md)
chapter.

## Run

Save as `countdown.ki` and:

```bash
koskari countdown.ki
```

Expected:

```text
3
2
1
lift-off
```
