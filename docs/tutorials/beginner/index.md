# Little Koskari

A first programming language, taught by asking. Each chapter is a run of
questions with their answers beside them. Read the question, decide what
you think the answer is, then read the answer. When a rule appears in a
box, it is one to keep; there are only a handful.

You need the [Quickstart](../../quickstart.md) done first, so that
`koskari` starts a REPL and you have run a file. When a line begins with
`koskari>`, it is something you type at that prompt, and the line below
it is what Koskari shows.
