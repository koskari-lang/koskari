# Tutorials

Two tracks. Each is read in order, and each chapter builds on the ones
before it. Both need the [Quickstart](../quickstart.md) done first, so the
`koskari` command starts a REPL.

## Little Koskari

For readers new to programming. Every chapter is a dialogue: a question on
the left, the answer on the right, with the code in the answer. It starts
with words and punctuation and ends with a small program in a file.
[Start here](beginner/index.md).

## From Python

For readers who know Python. Each chapter sets the Python spelling beside
the Koskari one and then says what changed. The later chapters cover
classes, modules, errors, interop, and macros, and the track ends with
[worked examples](from-python/examples/index.md) to copy and change.
[Start here](from-python/index.md).

Both tracks lead into the [Guide](../guide/index.md), which explains each
mechanism in depth. Neither needs the reference open; where a chapter names
a form, it links to that form's page.
