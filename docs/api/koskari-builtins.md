```{admonition} Virtual module
:class: note

Importing ``koskari.builtins`` assembles the standard library from compiled bootstrap sources. The bootstrap loader package is not documented here.
```

Constant-resolution fallbacks (for example ``True``, ``False``, ``None``, and ``nil``) are omitted from this reference.
